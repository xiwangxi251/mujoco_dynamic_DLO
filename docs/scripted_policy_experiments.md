# 规则策略实验记录

本文档记录 Panda 动态线缆抓取规则策略 `DynamicCableGraspPolicy` 的统一评测、失败模式分析、未来预测时长消融和可重复性验证。本文所称“规则策略”对应 benchmark 的 `scripted` 方法，不包括 PPO、DynamicVLA 或使用仿真特权信息的 `FormulaInterceptExpert`。

> 更新日期：2026-08-24  
> 实验完成时代码状态：`6ecf169 docs(eval): record long-horizon extension`  
> 当前默认预测时长：APPROACH/INTERCEPT `0.30 s`，CLOSE `0.12 s`

## 1. 实验目标

规则策略使用线缆节点状态和 Panda 运动学完成以下状态机：

1. 等待线缆运动稳定并完成夹爪姿态对齐；
2. 接近回合开始时随机选择的目标节点上方；
3. 锁定一个材料线段并下降截获；
4. 任意真实线缆中心线进入夹持中心 `1.8 cm` 范围后闭爪；
5. 形成双指确认抓取后抬升、侧移并满足严格成功判定；
6. 失败时竖直撤离并重试，最多重试两次。

本轮重点研究规则策略对运动线缆位置采用的线性外推：

```text
predicted_position = current_position + horizon × clipped_velocity
```

其中速度按每轴 `[-0.8, 0.8] m/s` 截断，预测点经过 `target_filter_alpha=0.10` 的低通滤波，并限制在安全截获空间内。

## 2. 策略关键参数

| 项目 | 默认设置 |
|---|---:|
| APPROACH 预测时长 | 0.30 s |
| INTERCEPT 预测时长 | 0.30 s |
| CLOSE 预测时长 | 0.12 s |
| 真实指垫接触后的预测时长 | 0 s |
| 预测目标低通系数 | 0.10 |
| 闭爪触发距离 | 0.018 m |
| APPROACH 超时 | 6.0 s |
| INTERCEPT 超时 | 9.0 s |
| 最大重试次数 | 2 |
| 控制频率 | 50 Hz |

在50 Hz下，`alpha=0.10` 的一阶低通对匀速目标约产生 `0.18 s` 的稳态滞后。因此名义 `0.30 s` 外推并不等于机器人命令始终真实领先0.30秒，这也是本轮进行 horizon 消融的原因。

## 3. 统一评测协议

### 3.1 固定场景

| 场景 | 运动组成 |
|---|---|
| `id_static` | 无主动线缆运动 |
| `id_rigid_l1_nominal` | L1单程整体平动与有限旋转，shape-hold保持线缆形状 |
| `id_shape_nominal_current` | 去净平动、净转动的局部准周期形变 |
| `id_combined_l1_nominal` | 与rigid相同的L1整体运动，加局部形变且不启用shape-hold |

### 3.2 固定并行与随机设置

```text
episodes per scenario = 25（正式基线另有50回合）
seed                  = 20280804
scenario_workers      = 4
envs_per_scenario     = 4
workers               = 16
recording             = enabled
```

每个25回合实验使用 seed `20280804–20280828`。不同 horizon 使用完全相同的场景和 seed，允许做逐回合配对检验。每组均保存 `episodes.csv`、`summary.json`、`manifest.json`、FULLPHYSICS轨迹以及全局/腕部视频。

## 4. 0.30 s 正式规则策略基线

结果目录：

```text
/data1/hxai/mujoco/mujoco_dynamic_DLO/outputs/benchmarks/
    scripted_4x50/run_20260824_021650/
```

该实验对四场景各运行50回合：

| 场景 | 成功数 | 成功率 | Wilson 95%区间 |
|---|---:|---:|---:|
| Static | 38/50 | 76% | 62.6%–85.7% |
| Rigid L1 | 4/50 | 8% | 3.2%–18.8% |
| Shape | 21/50 | 42% | 29.4%–55.8% |
| Combined L1 | 12/50 | 24% | 14.3%–37.4% |
| 总体 | 75/200 | 37.5% | 31.1%–44.4% |

### 4.1 失败类型

- 200回合中有84回合形成过双指候选，83回合达到确认抓取，75回合严格成功；
- 125个失败中116个属于 `never_bilateral_candidate`，占92.8%；
- 一旦确认抓取，总体严格成功率为 `75/83=90.4%`；
- rigid 一旦形成双指候选即 `4/4` 成功。

因此规则策略的首要瓶颈是接近和截获，不是抓住后的保持或滑脱。

### 4.2 Rigid 为什么低于 Combined

同一批50个配对seed中：

| 配对结果 | 回合数 |
|---|---:|
| 两者都失败 | 35 |
| 仅Combined成功 | 11 |
| 仅Rigid成功 | 3 |
| 两者都成功 | 1 |

两个场景使用相同L1刚体路径和相同初始随机量。差别是rigid用shape-hold保持整体形状，而combined的局部形变可能把其他线段摆入夹爪附近。策略虽然开始时追踪随机目标节点，但闭爪条件检查整条线缆的最近点，任务也允许抓住任意线段：

- rigid的4次成功全部抓到非初始目标节点；
- combined的12次成功中11次抓到非初始目标节点。

所以combined的额外形变在当前任务定义下会增加“其他线段偶然进入夹爪”的机会。该现象属于策略、场景运动和成功判定的相互作用，没有证据表明场景配置或仿真环境损坏。

## 5. 未来预测时长消融

### 5.1 实验设计

消融只同时修改 APPROACH 和 INTERCEPT 的预测时长，CLOSE 始终保持 `0.12 s`。0.30基线取正式4×50实验的前25个相同seed，其余horizon各重新运行四场景×25回合。

实验分为两批：

```text
/data1/hxai/mujoco/mujoco_dynamic_DLO/outputs/benchmarks/
    scripted_horizon_sweep_4x25/
    scripted_horizon_extension_4x25/
```

首批测试 `0.12/0.18/0.24/0.36/0.42 s`；扩展批重复测试0.42，并增加 `0.48/0.54/0.60 s`。

### 5.2 全部成功率

| Horizon | Static | Rigid L1 | Shape | Combined L1 | 总体 |
|---:|---:|---:|---:|---:|---:|
| 0.12 s | 18/25 (72%) | 0/25 (0%) | 7/25 (28%) | 6/25 (24%) | 31/100 (31%) |
| 0.18 s | 18/25 (72%) | 0/25 (0%) | 6/25 (24%) | 4/25 (16%) | 28/100 (28%) |
| 0.24 s | 19/25 (76%) | **7/25 (28%)** | 7/25 (28%) | 8/25 (32%) | 41/100 (41%) |
| 0.30 s | 19/25 (76%) | 2/25 (8%) | **12/25 (48%)** | 4/25 (16%) | 37/100 (37%) |
| 0.36 s | 18/25 (72%) | 5/25 (20%) | 8/25 (32%) | 8/25 (32%) | 39/100 (39%) |
| 0.42 s | 18/25 (72%) | 6/25 (24%) | 11/25 (44%) | 8/25 (32%) | **43/100 (43%)** |
| 0.48 s | 18/25 (72%) | 4/25 (16%) | 8/25 (32%) | 6/25 (24%) | 36/100 (36%) |
| 0.54 s | 19/25 (76%) | 1/25 (4%) | 7/25 (28%) | **10/25 (40%)** | 37/100 (37%) |
| 0.60 s | **20/25 (80%)** | 2/25 (8%) | 7/25 (28%) | 8/25 (32%) | 37/100 (37%) |

### 5.3 主要趋势

1. static保持72%–80%，horizon影响很小，符合静态目标速度接近零的预期；
2. rigid对horizon最敏感：0.12和0.18均为0%，0.24达到最高28%；
3. shape在0.30最好，为48%，0.42接近，为44%；
4. combined在0.54最好，为40%，但同组rigid只有4%；
5. 总体最好的统一horizon是0.42，为43%；继续增加到0.48–0.60后，总体下降到36%–37%；
6. 不存在对所有动态场景都单调更优的单一horizon，说明固定外推时长存在场景权衡。

## 6. 可重复性验证

0.42使用相同配置完整重测一次。两次结果均为：

```text
Static 18/25
Rigid  6/25
Shape  11/25
Combined 8/25
Total 43/100
```

逐seed比较100个回合后，以下字段全部零差异：

- 严格成功；
- 是否形成双指候选；
- 是否达到确认抓取；
- 终止原因与失败类型；
- 控制步数与仿真时间；
- 最小目标距离；
- 最终抓取节点。

这说明当前benchmark在固定seed和配置下可确定复现，0.42的43%不是并行调度产生的偶然波动。

## 7. 统计分析

首批六个配对horizon的Cochran Q检验：

| 范围 | 统计量 | p值 | 结论 |
|---|---:|---:|---|
| 四场景合并 | `Q(5)=14.83` | 0.0111 | 存在总体horizon效应 |
| Rigid L1 | `Q(5)=18.68` | 0.00220 | horizon效应显著 |
| Static/Shape/Combined | — | >0.05 | 单独未达到显著 |

扩展到全部九个horizon后：

| 范围 | 统计量 | p值 |
|---|---:|---:|
| 四场景合并 | `Q(8)=14.49` | 0.0699 |
| Rigid L1 | `Q(8)=25.58` | 0.00124 |

新增0.48、0.54、0.60相对0.42的总体配对McNemar检验均未达到0.05。0.24相对0.30的rigid结果最接近显著：新增成功5、丢失成功0，双侧精确 `p=0.0625`。

单场景每组只有25回合，Wilson区间仍较宽。当前统计支持“horizon确实影响rigid”，但不足以证明0.42是唯一全局最优值。

## 8. 失败模式随 Horizon 的变化

规则策略在不同horizon下的主要变化发生在形成双指候选之前：

- horizon过短时，单程整体运动造成持续追踪滞后，rigid几乎无法让线缆进入1.8 cm闭爪范围；
- 中等horizon改善rigid截获，但不同形变场景的局部速度变化会改变预测点和状态机切换时刻；
- horizon过长时，局部线性速度对0.5–0.6秒后的形变预测误差增大，并可能让目标更频繁触及截获空间裁剪边界；
- 一旦形成双指确认抓取，大多数回合仍能成功，因此优先应改进预测和截获，而不是继续增强夹持力。

0.54对combined提高但对rigid退化，进一步说明“固定线性外推”无法同时适配整体单程运动与局部非刚性形变。

## 9. 当前结论

1. 当前默认0.30不是最均衡的统一值；其shape最好，但rigid和combined较弱。
2. 0.12–0.18对rigid明确过短。
3. 0.24是rigid最佳候选，但shape明显低于0.30和0.42。
4. 0.42在九个候选中总体成功率最高，并在四场景间表现最均衡，是当前推荐的统一候选值。
5. 0.48–0.60没有带来总体收益；0.54只对combined局部有利。
6. 下一步不宜继续盲目增加固定horizon，应比较场景无关的自适应预测或多horizon候选机制。

## 10. 后续实验计划

### 10.1 扩大候选点样本量

优先将以下三组扩展到每场景至少50个相同seed回合：

- `0.24 s`：rigid最佳；
- `0.30 s`：现有默认且shape最佳；
- `0.42 s`：当前总体最佳。

### 10.2 记录截获过程诊断

建议在逐步日志中增加：

- 原始目标位置、线性外推位置和低通后目标位置；
- TCP到随机目标节点与整条线缆最近点的距离；
- 目标速度及预测位移；
- 预测点被xyz安全范围裁剪的比例；
- APPROACH进入INTERCEPT、INTERCEPT进入CLOSE的时刻；
- 锁定线段索引、实际抓取线段索引及两者差值。

### 10.3 方法改进方向

优先比较以下方案，而不是继续把统一horizon增大到0.60以上：

1. 根据目标速度、TCP距离和预计到达时间选择自适应horizon；
2. 在多个候选horizon中选择可达性代价最低的截获点；
3. 减小低通造成的固定滞后，同时保留接触抖动抑制；
4. 使用整条线缆的可抓线段候选，而不是长期追踪单个随机目标节点；
5. 分离整体刚体速度与局部形变速度，避免用单一线性外推处理两类运动。
