# 环境端进度

> 更新时间：2026-08-28  
> 范围：只记录 MuJoCo 环境、线缆运动、场景定义、观测和任务判定，不记录具体策略的训练结果。

环境端的目标是为不同方法提供同一套动态线缆抓取任务，使规则策略、RL 和视觉模仿学习方法能够在

[`environment.py`](../src/panda_cable_grasp/env/environment.py)和
[`registry.py`](../src/panda_cable_grasp/scenarios/registry.py)。

## 2. 当前环境接口

- 底层环境为 `CableGraspEnv`，通过 `EnvConfig` 统一配置物理参数、运动形式、相机和机器人限制。
- `reset()` 支持指定 seed；相同 seed 可用于不同方法或场景之间的配对比较。
- 底层动作是 8 维 Panda 执行器控制量。环境以 50 Hz 接收动作，每个动作内部执行 10 个
  500 Hz MuJoCo 物理子步。
- 原始状态观测包含机械臂关节、末端位置、目标线段及全部线缆节点位置。这些线缆状态属于仿真
  特权信息；各方法是否可使用，需要在对应实验协议中明确限制。
- 可选视觉观测包含一个固定视角相机和一个腕部相机，默认分辨率为 480×360。
- `info` 中记录场景 ID、运动参数、线缆状态、抓取阶段、接触力、滑脱原因、动作限幅和成功状态，
  用于统一评测与失败分析。

## 3. 线缆运动与场景

### 3.1 四类基础运动

| 类型 | 当前实现 |
|---|---|
| `static` | 不施加主动线缆运动 |
| `rigid` | 线缆沿 L1/L2 轨迹整体平移并发生有限旋转，同时尽量保持初始形状 |
| `shape` | 去除整体平移和旋转分量，主要产生线缆内部形状变化 |
| `combined` | 同时施加整体平移/旋转与内部形状变化 |

L1 为较简单的单向轨迹，L2 为带横向变化的曲线轨迹。二者当前都保留在场景注册表中，最终采用
哪一级作为论文主实验条件尚未冻结。整体运动在确认抓取期间会暂停，形状变化在 `combined` 场景中
继续施加。

### 3.2 形状变化因素

- 幅度：`low / nominal / high`；
- 频率：`low / nominal / high`；
- 规律性：`regular / quasiperiodic / stochastic`；
- 幅度和频率可以独立配置，开发场景中已经包含独立扫描条件。

所有新注册场景共享随机弯曲初始形状分布，并保存 scenario ID、scenario hash 和 motion profile hash，
便于复现实验条件。

### 3.3 OOD 条件

当前已注册以下 OOD 环境变体：

- 更高幅度、更高频率且随机参数化的组合运动；
- 线缆长度缩短至标称值的 80%，或增加至 120%；
- soft 材质：降低质量、刚度、阻尼和摩擦；
- stiff 材质：提高质量、刚度、阻尼和摩擦。

这些变体已经能够映射到 MuJoCo 模型参数，但尚未完成正式的大规模 OOD 对比实验。

## 4. 抓取与成功判定

环境通过双侧指垫接触、法向力、夹爪开口和连续接触时间确认物理抓取，并记录主动张爪、接触丢失
和物理滑脱等不同失败原因。任务成功要求：

1. 夹爪保持闭合并形成已确认的双指抓取；
2. 被抓线缆节点达到规定高度；
3. 足够比例的线缆被抬离桌面；
4. 线缆仍保持在夹爪附近；
5. 上述状态连续保持规定时间。

所有策略最终使用环境端同一成功状态，不允许方法封装单独降低成功门槛。

## 5. 当前未完成的问题

1. L1/L2 主场景、幅度与频率范围、正式 seed 清单和 `paper` suite 尚未最终冻结。
2. 当前线缆运动由环境直接施加外力/加速度生成，适合控制变量，但与真机上的实际驱动装置并不
   完全等价；真机如何产生可控、可重复的形状变化仍未确定。
3. 环境可以直接输出完整线缆节点状态，但真机端尚无对应的实时 DLO 状态感知模块。
4. 图像观测接口已经具备，但环境随机化和视觉 sim-to-real 条件还不完整。
5. 长度和材质 OOD 已实现参数化，仍需检查不同参数下的数值稳定性、物理合理性和任务难度可比性。
6. 外工作区的任务空间控制仍在诊断，尚未形成冻结后的环境回归结论。
