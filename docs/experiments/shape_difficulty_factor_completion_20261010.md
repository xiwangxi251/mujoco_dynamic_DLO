# 完整形状难度：补全实验

本文件记录预先固定的补充范围；不是实验结论。前一批1000个候选只完成了部分因素分析。

输入：`outputs/shape_difficulty_formal_1000_20261010/` 中872个合格回合的结果与完整仿真状态。
输出：该目录下 `factor_completion/`。冻结源、配置标识和所有阶段写入 `manifest.json`。

## 阶段与验收

1. 重建872回合的运动学与碰撞接触，不推进物理时间：候选和所选区域的弯曲、支撑跨度、净空；首次闭爪的方向、位置、包围深度与接触类型；接近路径、指垫提前接触、限位与任务雅可比。核对节点重建误差。执行时特征只作事后诊断，不用于初始形状预测。
2. 根据几何特征覆盖选择64个不同源轨迹的形状，不按成功或失败选样；复用其几何选点基线。新增1472回合：
   - 中间可达候选、最近可达候选两种选点，各64回合，共128回合。
   - 世界X/Y目标偏差各±5/±10 mm，以及yaw偏差±5/±10度，共12条件×64＝768回合。
   - 完整形状X/Y平移各±30 mm，以及绕质心旋转±15度，共6条件×64＝384回合。
   - 每个形状3次独立小标定偏差重复，共192回合。XY各从N(0,2 mm)、yaw从N(0,2度)抽取固定偏差；种子和实际偏差逐回合保存。它们测量同一误差分布下的稳定性，不冒称名义条件下的独立随机成功率。
3. 对64个基线目标做固定中心的静态IK探针：原朝向及yaw偏移−45、+45、+90度。限位内搜索，不推进物理，不作为规则规划。求解失败不证明全局不可达，求解成功不认证执行路径无碰撞。
4. 汇总全部因素、预先指定的相互作用、匹配形状对照、源轨迹隔离的预测，以及留出64个来源后的跨选点规则验证。匹配阈值固定为稳健尺度下RMS距离≤0.20、对照因素差异≥0.50；每类最多32对，不复用来源，不为凑数放宽。无合格匹配时如实报告不足。
5. 按规则选点、容错、布局各渲染一个代表回合；保存全部新增回合的可重渲染状态。视频使用项目命名全局、腕部相机，加入原播放入口 `http://127.0.0.1:8792/index.html`。

三种规则共用材料点锁定、切线旋转、增强6有界DLS、碰桌保护、0.82秒等待、15秒预算与成功标准。不使用专家仿真前推。布局只对完整形状作刚体变换；不改变材料参数。

## 解释边界

- “可达候选”仅按现有工作区与执行坐标限制筛选，不是完整位姿可达认证。
- 容错测试记录重试后的最终成功和首次尝试成功；有限偏差网格不等于连续物理容错边界。
- 候选评分中的净空和方向是近似几何指标，与实际执行配置分开报告。
- 布局属于任务条件，单独分层，不把位置直接算成形状复杂度。
- 匹配对照仍可能残留几何耦合，报告匹配程度；不能仅凭关联宣称因果。
- 本阶段的跨策略验证限于三种规则选点方法，不能推广为PPO/DP的普适难度。
- 全部阶段结束才交付补全报告；小批验证、状态分析或新增回合结束均不是整体完成。

小批验证与故障探针保存在独立输出目录，不计正式回合。
