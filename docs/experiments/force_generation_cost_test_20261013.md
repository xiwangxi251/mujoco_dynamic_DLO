## 直接生成力：6组均失败

实验公式用初态节点几何、预定单向平移和原24° smoothstep转角计算节点
加速度，平移起步用原32/s速度增益的指数响应。再加入模型摩擦系数
`mu=2` 的 `mu*m*g` 补偿，水平加速度按原8m/s²限幅；不调用 MuJoCo
步进生成力，不读取实际回合受干预后的位移或速度，不拟合参数。
纯整体运动在生成端假设初始构型刚体共动，没有原形状保持反馈的精确等价力；
组合运动真实回合仍计算原形变力。这个近似是本次受测公式的限制。

表中两值分别为种子20260804 / 20260805，窗口为0.82～2.00秒：

| 场景 | 质心位置 RMSE（cm） | 质心速度向量 RMSE（m/s） | 质心均速偏差 |
|---|---:|---:|---:|
| 简单初态整体运动 | 54.95 / 53.72 | 1.037 / 1.013 | +452.8% / +442.0% |
| 复杂初态整体运动 | 16.92 / 53.68 | 0.364 / 1.019 | +149.0% / +442.8% |
| 组合运动 | 48.70 / 46.24 | 0.917 / 0.903 | +379.1% / +380.3% |

原阈值保持：质心位置RMSE<=5mm、质心速度向量RMSE<=0.025m/s、
均速偏差<=5%、转角RMSE<=0.025rad；材料点差异另记，原位置峰值20mm
阈值也未放宽。没有把测试缩短后的数据称为完整15秒精度验收。

简单初态seed20260804在回合2秒时，原驱动质心前移0.2496m，
候选前移1.3717m；节点20速度由原0.2136m/s变成1.7333m/s。
按mu*m*g估算的阻力补偿达19.62m/s²，限幅后仍持续驱动8m/s²。
这套估算未刻画真实线缆的接触/滚动/约束，出现严重超速。
结果否定的是该公式，不证明简单单向运动必然需要完整预模拟，也不证明
所有解析驱动力方案都不可行。测试后未调小系数或提高力上限。

2秒力序列生成耗时 4.89～8.23ms，
成本低但运动不合格；未以速度快为理由采用。

## Shape replay 离线加载：6条均与原播放完全一致

为防止暗中回退在线编译，测试将 `prepare_force_replay` 置为空，并将
`compile_force_replay` 替换为直接报错。载入已有节点力后，使用原播放、
逐节点桌面接触关断及持续时钟机制。仍用原低层物理检查，无夹爪干预。

- 六条各15秒，跟踪位置/速度最大绝对差 **0**。
- 每20ms捕获完整 MuJoCo integration 状态，六条逐帧状态最大绝对差 **0**。
- 全部已有力文件hash、力数组hash和原轨迹文件hash一致。
- 加载加校验耗时 25.57～29.71ms，
  平均 26.85ms；在线生成端物理步数为0。
- 同seed20260804：原15秒在线编译 77.16s、7500个物理步；
  离线载入 26.37ms。
  原编译重新得到的力hash与已有文件一致。这是额外预生成成本比较，不是
  整个训练吞吐提升倍数；真实15秒回合仍需正常物理仿真。
- 每条原始float64力数组为7500×40×3，7.2MB（十进制），不含索引或轨迹。

适用范围严格限定为同源条目、材料节点、初态、摆放、物理参数、运动时间缩放、
步长及驱动参数。未测试不同随机种子、材质、长度、速度难度之间共用一个力文件，
不能靠这个结果声称训练的任意随机化都已支持。生产实现还需要明确的库生成范围、
配置/初态身份匹配、缺失条目处理；本轮未部署加载器，也没有隐式在线生成兜底。

离线加载保持原误差，不能消除源轨迹复现限制：之前full50中14/50至少一项
超原门槛；位置RMSE最大9.082mm、速度向量RMSE最大0.07017m/s、
位置峰值最大56.09mm、回合均速偏差最大2.84%。本轮未改这些阈值或结果。
