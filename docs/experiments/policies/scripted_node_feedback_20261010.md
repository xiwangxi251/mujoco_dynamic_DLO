# 规则策略：只用节点与机器人状态反馈

- 默认 `use_contact_feedback=False`。策略不读取指垫接触、法向力、抓取候选／确认／断开、被夹节点身份或成功计时。专家单独保留原接触反馈配置。
- 闭爪时锁定材料线段及插值比例；闭爪0.8秒后直接抬升。进入抬升时记录该材料点高度；1秒后升高不足3厘米，张爪撤离并重试。
- 侧移和保持时，同一材料点相对抬升起始高度低于3厘米，也重试。不增加指间位置或同步运动判断。
- 原接近／下探超时、姿态与奇异性检查、张爪后1秒抬高18厘米、剩余时间至少3秒的重试机制保留。
- 几何选点脚本用有序节点构造中心线，以不超过2毫米间距采样；线缆半径、机器人夹爪几何与工作区为已知参数。不读取线缆碰撞体位姿，不进行仿真前推。
- 环境内部接触物理、运动驱动和公共成功判据不改。成功统计和回合终止由外层评测负责。
- 测试入口：`tools/evaluation/run_node_feedback_family.py`；7场景各10回合，本机8进程，只统计结果，不录视频。复杂初始形状复用之前合格10快照，其它场景用相同种子。
- 每回合用代理禁止策略读取接触、抓取和成功字段；违反时直接报错。结果另存阶段变化、失败原因、配置和源码哈希。
- 首轮遗漏了可重渲染状态保存。补跑入口为 `tools/evaluation/run_node_feedback_state_family.py`，保存每控制步的 `mjSTATE_INTEGRATION`、动作、时间戳、目标、夹爪目标姿态及环境／项目相机配置。暂不渲染视频；后续可直接生成双视角视频，不再运行策略。输出 `outputs/scripted_node_feedback_states_seven_20261010/`。
