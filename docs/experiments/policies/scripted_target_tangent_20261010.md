# 规则策略跟随目标切线旋转

- 默认开启：`PolicyConfig.follow_target_tangent=True`，规则 CLI、benchmark 和场景族录像入口一致。关闭使用 `--no-follow-target-tangent`；benchmark 使用 `--scripted-option follow_target_tangent=false`。专家策略及显式关闭的历史对照配置保留。
- 未锁定线段时，用目标节点左右邻点的中心差分；锁定后，用该材料线段的切线。使用当前几何的 XY 投影，不增加朝向预测。
- 绕世界竖直轴旋转，使夹爪闭合方向与切线垂直。180° 等价朝向选离上一次目标朝向最近的一支；水平切线退化时保持上一次朝向。
- 接近、下探、闭爪阶段更新朝向；抓取确认后保持朝向进行抬升。闭爪触发、选点、重试、速度和接触参数不变。
- 新测试：持续形变 `dev_shape_nominal_current_x075_v1`、复杂静态 `dev_static_midshape_v1_x075_v1`，各10回合，种子20260804–20260813；当前dev场景的0.82秒等待、增强6＋有界DLS、碰桌保护开启。
- 复杂静态仍使用现有快照，此前记录的5mm筛选尚未实施；不将这次结果直接归因为旋转开关的效果。
- 单关节测试：其他关节保持就绪指令，第7关节从约88.2°反向转90°。保持原伺服、速度限制和碰桌保护；记录实际角度、速度、到位时间及其他关节的实际偏移。
