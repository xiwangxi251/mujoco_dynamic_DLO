# 固定夹持中心的世界 Z 轴旋转诊断（2026-10-10）

`outputs/scripted_world_z_rotation_20261010/`记录了夹持中心从(0.70, 0, 0.25)m出发、保持不动并请求绕世界Z轴正向旋转90°的诊断。500Hz轨迹在1.764s偏移峰值191.2mm，12s终点仍偏移74.4mm。碰桌保护与几何防撞均未介入。

现有增强6有界DLS以位置和姿态残差联合最小二乘，没有位置硬约束或姿态退让预算。正向旋转触及第6关节下限；1.50s虽请求回到原中心，受限解的平移方向仍朝外。静态有界搜索在有限起点内未找到正向90°零误差解，但这不证明全局不可达；反向若干角度的低误差解也未做动态碰撞验证。

因此，固定中心旋转存在可达性与控制优先级风险。峰值偏移来自动态轨迹，不能由静态搜索单独解释。今晚的形状难度研究固定使用现有竖直夹爪朝向（`follow_target_tangent=False`），结果只适用于该朝向与当前执行控制；不把本次研究解释为旋转能力或跨策略的普适形状难度。
