# 指定点奖励 v3：下降扣回预算与矩形工作区

2026-10-06，用户要求修正抬升进度的重复扣分并应用已选矩形工作区。

## 进度账本

`tolerance_progress_v3` 保留 v2 的首次位置奖励、成功±2/位置正奖励±4、容差外递减正奖励、高水位防重复领奖及延迟释放判定。唯一奖励机制变化：节点高度与线缆抬起比例各自维护一份整回合的下降扣回余额。

- 新历史进度实际发出的正奖励，为相应余额充值；余额按已应用目标误差折扣后的进度计算。
- 持续夹持时出现下降，可以扣回相应余额，扣回后余额减少。
- 回到历史高度不再发正奖励；再次下降也不能重复扣回已经耗尽的余额。
- 重抓、切换节点、目标误差变化均不清空账本。
- 未夹持时的外力抬升不发奖励，也不充值扣回余额。
- 实际滑脱、主动开爪的独立惩罚仍按原有资格及次数上限执行。成功判定、观测109维与动作5维不变。

示例（正确目标、从0开始，仅节点高度项）：首次升10cm发+4，夹持回落可扣-4；再升至10cm发0，再回落扣0；升到12cm只发新增2cm的+0.8，后续下降最多扣回这+0.8。各进度项整回合累计扣回不会超过本项实际已发正奖励。

实现：`rl/lift_credit.py`；v3在正式环境reset时启用`bounded_debits=True`。v2仍走原无限重复下降扣分路径，供历史复现，不能把旧统计改标为v3。

## 工作区

新指定点PPO在默认`cable_x075_v1`族中使用：

- X：0.60～0.84m；Y：−0.22～0.30m，包含边界。
- 初始目标节点的Z条件仍为−0.005～0.10m。
- 4cm网格，6列×13行共78格，全部接受；显式矩形边界避免角点被浮点舍入排除。
- 文件：`src/panda_cable_grasp/rl/workspaces/rectangle_060_084_m022_030.npz`，作为包数据安装。
- 这是目标采样工作区，不是机械臂运动裁剪框；固定材料目标离开框后继续跟踪。
- 显式`--target-workspace`继续优先，历史84格掩码可以原样使用。显式其他场景列表/旧场景族不自动套用此矩形。
