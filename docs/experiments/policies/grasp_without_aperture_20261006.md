# 去掉固定开度夹持资格

2026-10-06用户要求去掉固定开度资格，并同步奖励判定。本修改接续
[50 mm修改](grasp_aperture_050_20261006.md)，不再用40/50 mm或对象厚度推算的开度上限决定夹持。

## 实际判定

- 首次夹持：同一对象局部线段邻域内，两侧内指垫法向力各至少0.20 N；
  节点到夹持中心距离不超过55 mm；连续确认0.06秒。邻域和候选间断条件沿用原配置。
- 保持与公共成功：保留已确认状态、实际接触证据、0.35秒接触丢失宽限；
  底层距离超过82.5 mm立即清除夹持。开度增大本身不再清除夹持。
  张开导致双侧接触丢失时也遵循接触宽限，不再因超过绝对开度门限而立即清除。
- 公共成功仍要求目标节点容差、高度、线缆抬起比例和0.80秒连续保持；不修改这些数值。
- 稳定夹持与抬升计奖：删除统一开度检查，继续要求确认夹持、距离不超过55 mm，
  以及对应承载高度、确认时间和接触宽限。与底层不再存在粗线缆开度资格不同步的问题。

这里的几何条件仍是现有中心距离，未新增“必须位于两指之间”或插入深度门限。
夹爪动作行程、速度限幅、TableExecutionGuard和线缆摩擦、尺寸及物理均保持原实现。
旧`max_grasp_aperture`、对象`aperture_limit`保留为旧调用/快照兼容字段，但不参与上述资格。

## 奖励与释放

此前仅因实际开度超过上限而漏掉的有效夹持，可以获得稳定夹持、节点抬升、线缆比例和保持奖励。
权重、递减目标容差、高水位、防重复领取和下降扣回没有改动。
接触丢失超过宽限、距离越界或抓取状态清除后仍停止正奖励，并按原账本扣回已有抬升收益。
宽限内的持有可能继续计奖，沿用同一个确认状态。

主动张开惩罚的因果分类仍只在真实夹持丢失后进行；实际开度相对张开指令开始时增大作为
张开证据，去掉旧绝对开度条件。单独OPEN指令不等于已经松脱，原歧义类别保留。

新标记：`physical_holding_v3_no_aperture`、`confirmed_distance_grace_v4_no_aperture`、
`grasp_aperture_qualification_enabled=false`。v6稳定夹持和抬升标记为
`confirmed_distance_contact_grace_v3_no_aperture`。训练、评估及各方法的运行记录同步标记。

## 针对性检查

29项测试通过，覆盖：60 mm有效双侧夹紧仍可确认；缺少一侧夹紧力或距离越界不可确认；
70 mm已确认持有可获得抬升和稳定夹持奖励；接触宽限过期后停止计奖；下降扣回、
主动释放惩罚只消费一次，以及OPEN命令本身不清除真实持有。

旧录像和训练统计保持冻结口径。本地dev的修改不会自动进入151已启动的训练进程。
