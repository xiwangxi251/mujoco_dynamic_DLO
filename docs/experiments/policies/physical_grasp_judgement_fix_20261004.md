# 抓取判定修正：physical_holding_v2

## 已实施的修改

- 环境 `_update_physical_grasp_state` 不再因夹爪目标被判定为 OPEN 清除状态。
  命令仅标注可能的释放意图。实际状态由双侧接触候选、确认状态、实际指距、
  局部线段与夹持中心距离以及接触丢失宽限决定。
- 实际几何已失效（实际指距超过该对象已有的 aperture_limit，或持有节点
  离开既有 1.5×max_pad_distance 范围）立即产生 `physical_grasp_geometry_lost`。
  接触候选丢失沿用候选 0.02 s / 确认后 0.35 s 宽限。
- 已确认后的法向力暂时不足，如果附近同一对象的双侧真实手指接触仍在，继续保留状态。
  首次候选建立的力阈值保持现有 0.2 N；未添加基于命令的候选门槛。
- `_success_qualification` 不再依赖闭爪目标。成功计时需要当前有效几何、
  已确认抓取、持有节点附近的双侧指垫接触，以及既有抬升高度和比例。
  保留状态的接触宽限本身不能累计成功保持时间，保持要求仍为 0.8 s。
- PPO `_update_grasp_status` 使用同一局部双侧指垫接触条件；移除稳定抓牢
  接触宽限对 `_gripper_closed` 的依赖。严格成功保持仍要求当前双侧接触。
- 松开/滑脱事件仅随实际状态清除产生，奖励消费同一个物理事件一次。
  真实指距超过夹持范围且有此前开爪意图、此前未进入接触丢失计时，才归入 active_open。
  开爪期间原因不明确的实际脱离归入 open_during_contact_loss，与滑脱共享原轻惩罚。
  这属于诊断分类，不能据命令单独断言物理因果。既有奖励系数、每回合扣分上限保留。
- `info.grasp_judgement_version=physical_holding_v2` 标记新定义；active_open_break_count /
  physical_slip_break_count 现在按 causal_class 计数。旧录像及冻结基线未修改。

## 与“抓住后反复上下起伏”的关系

本修正消除命令造成的假松开、假重抓和成功计时中断，但不能保证已有权重立即
改变动作。新状态可能进入策略观测，从而改变闭环轨迹，实际效果需上述对比确认。

此前审计发现的真实脱离后的抬升信用重置仍存在：height_band分支在无pinch时清空
高度势能基准，线缆抬起比例在无pinch时推进基准而不结算下降。因此实际脱离、掉落、
重抓仍有重复领取进度的机会。若要修此奖励漏洞，应在实际状态丢失时结算未完成
信用，或统一连续势能，且避免将外界自然抬升奖励给策略；需要单独变更和配对验证。
本次仅实现已批准的判定及事件一致性修正，不改变这部分奖励机制。
