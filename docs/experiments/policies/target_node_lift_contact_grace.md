# 指定点PPO抬升奖励接触宽限（2026-10-06）

## 证据与范围

固定4999200步旧v5录像808，13.64秒仍有双侧接触，被夹节点离桌27.379mm，低于整回合45mm高度高水位；13.66秒双侧接触消失，但确认夹持仍在、实际开度28mm、节点与夹持中心相距7mm；13.68秒高度53.067mm超过高水位，原奖励因`raw_bilateral=False`不支付。之后抬起比例达到45%，同样没有计奖。该例说明原始接触即时门限与已有确认夹持口径不一致；不能将零奖励理解为没有实际上抬。

## 修正

默认`tolerance_progress_v6`抬升正奖励改用底层`grasp_confirmed`：必须曾确认双侧夹持，距离最后双侧接触不超过已有`grasp_loss_seconds=0.35s`。实际开度须≤50mm（2026-10-06按用户要求由40mm调整，见[开度修改记录](grasp_aperture_050_20261006.md)），被夹节点与夹持中心距离仍须≤55mm；几何失效、确认状态清除、宽限过期立即停止支付。OPEN命令本身不等同于实际失去夹持，沿用已修复的物理口径。首次未确认的单侧接触不能通过宽限获得正奖励。训练配置记录`lift_reward_holding_version=confirmed_geometry_contact_grace_v2`和实际宽限秒数。

同时修正同类的`secured`首次承载确认：原来先要求双侧接触连续0.10s才能进入0.06s滞回，首次确认前的接触抖动不断清零。v6承载候选仍要求原几何和节点相对初态抬升≥3cm，但候选连续0.10s使用同一已确认夹持宽限，后续承载保持也沿用0.35s。标记`secured_grasp_accounting_version=confirmed_geometry_contact_grace_v2`。稳定抬起奖励仍为一次性4分；已有释放处罚的金额、次数和因果分类规则不变。几何失效不宽限。v2～v5显式旧配置保留旧行为。

整回合高水位、防重抓重复领奖、材料节点收益记账及松爪后下降扣回均保留；本次未改变45mm初态高水位、正奖励权重或计奖上限。下降扣回不受接触宽限结束影响，继续跟踪已支付节点与比例。

## 其它检查结果

- 公共成功已有0.35s确认夹持宽限，v6保持奖励使用公共`success_hold`，无需再次修改。
- `strict_success_hold`及`height_band_hold`仍要求原始双侧接触，当前v6只将其作为严格诊断，不定义最终成功/保持奖励；保留以区分口径。
- 捏住事件、接近/对齐阶段切换和捏住不抬的会话处罚使用已确认夹持，不因一帧原始接触消失即切换。
- 单次首次接触奖励记录累计已接触手指数，不因短暂接触消失重新发奖。
- secured未确认会使稳定抬起奖励及后续释放处罚资格漏掉，相关影响由本次承载确认宽限修正处理；未改释放因果证据要求。

公共成功高度、比例、目标±2和连续0.80s均不变，物理、控制器、工作区、场景族、109维观测、5维动作、保护与缓存、48训练/13评估worker保持一致。保存当前完整检查点与优化器、课程阶段，用新目录保留20M累计预算续训，重新积累新奖励的晋级评估历史。
