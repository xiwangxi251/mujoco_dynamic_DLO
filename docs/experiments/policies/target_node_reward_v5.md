## 唯一机制修正

新`tolerance_progress_v5`仅将抬升/线缆比例记账的holding资格收紧为当前：

- 已确认夹持；当前目标附近有双侧指垫接触；
- 实际开口≤原`max_grasp_aperture`（0.040m）；
- 被夹节点与夹持中心距离≤原`max_pad_distance`（0.055m）。

不增加最小抬升门限：刚开始有效上抬也可领奖。状态失去资格时不发进度奖励，也不充值扣回余额；高水位继续观察，恢复接触或重抓不能把此前无接触高度重新领取。沿用v3/v4防重复记账，v2～v4可按显式配置历史复现。新的资格字段仅进入诊断info和配置元数据，不加入109维观测。

没有更改MuJoCo物理、接触力、夹持确认/宽限期、释放分类、成功高度与0.8s保持标准、执行器、TableExecutionGuard、矩形工作区、5维动作、普通PPO探索或训练并行数。原主动开爪/滑脱惩罚保持原样，没有强制训练策略闭爪，也没有新增保持奖励。

针对性测试覆盖宽限期无双侧接触不领奖、恢复接触同高度不重领、有效新高度与比例可领奖、开口过大及距离超限不领奖，以及v4历史行为保留。dev提交同步151，归档权重及优化器，从最新完整checkpoint在新v5目录续训，总预算仍20M。约新增100万步后复查确定性成功与稳定夹持；本次只确认奖励资格修正及正常启动，不宣称学习问题已解决。
