## 原因与范围

2026-10-06用户指出4999200步录像的种子20260806明显已经举住，但最长公共保持只有0.532秒。代码历史确认：10月5日夹持判定修复`1cd0897`（迁入dev为`2d618b4`）给公共成功额外加入了每个2ms物理步都必须有双侧指垫接触的条件。0.80秒数值没有改，但公共成功资格被收紧；此前“成功标准没有变化”的表述不准确。不能将0.532秒解释为实际只持有这么久。

公共判定现在标记为`public_success_version=confirmed_geometry_grace_v3`。使用已确认夹持、实际有效几何和已有0.35秒接触丢失宽限，恢复对短暂接触抖动的容忍。实际开度越界、距离越界、接触丢失超出宽限、抓取状态清除、高度/线缆比例/目标节点不合格仍会中断计时。宽限内合格时间继续累计，不新增宽限或改变状态机。

公共成功仍在500Hz检查：所持线段世界Z>0.14m、至少18%线缆节点世界Z>0.055m、原中心距离限制、目标节点±2，连续保持0.80秒。实际夹持状态不依赖单独OPEN/CLOSE命令，保留此前假释放修复。
