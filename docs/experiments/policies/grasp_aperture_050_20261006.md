# 有效夹持开度上限改为50 mm

随后用户要求[去掉固定开度资格](grasp_without_aperture_20261006.md)；本页记录中间的50 mm版本。

2026-10-06用户在种子20260806、节点10的规则测试后，明确要求将40 mm改为50 mm。

`EnvConfig.max_grasp_aperture`默认由0.040改为0.050 m，表示两指实际总开度。
对象运行时的默认值同步更新。普通14 mm半径线缆使用50 mm上限；其它尺寸
仍按原厚度公式修正，显式指定`ObjectSpec.grasp_aperture`的对象仍使用指定值。

候选夹持、持有几何、公共成功资格、RL稳定夹持和抬升奖励的开度检查继续
读取同一配置。双侧指垫力、局部线段邻域、距离、确认时间和接触宽限条件
均沿用原实现。50 mm以内并不单独构成抓取成功。

这是新的夹持判定配置。此前40 mm的冻结录像、成功统计和训练快照保留原口径，
不能将旧失败记录直接改为成功。正在151运行的已启动训练不会自动加载本地修改。

针对性检查保留48 mm实际夹持，并检查52 mm实际张开仍清除夹持、拒绝公共成功。
