# Shape replay 未抓牢阻挡处理（2026-10-13）

**历史记录：用户随后否定了本版“接触即停”规则，当前已由v4替代。**
当前规则见[接触不等于阻挡](shape_replay_obstruction_refinement_20261013.md)。

用户要求处理夹爪挡住线缆、尚未确认抓牢时，回放仍前进并在解除阻挡后追赶的情况。
本次初版曾为七场景族中的 **Shape replay** 配置 `continuous_ff_v3`。它保留 v2 的连续参考、
加速度前馈和全部跟踪增益，只增加接触暂停/恢复规则。

## 规则与范围

- 按物理子步读取 MuJoCo 线缆与左右手指、夹爪基座的接触。几何接触距离
  `dist <= 0` 即保守地视为阻挡，不要求两侧同时接触、不要求闭爪或抓取确认。
  手指外表面也覆盖；正距离 margin 接触、桌面接触、仅渲染几何和其它机械臂
  连杆不触发。轻微擦碰也会暂停，这是有意采用的保守规则。
- 触发后同步暂停回放时钟、平移/旋转驱动与形状保持驱动。线缆仍由物理引擎
  正常积分，仍可能受到夹爪推动、重力和接触力，不锁定真实节点位置或速度。
- 从最近一次接触起连续无接触 40 ms 才解除暂停，防止接触对抖动造成反复启停。
  若已确认抓取，即使接触暂停条件消失，原抓取暂停条件仍然有效。
- 最后一个暂停原因解除时，只重锚一次：把暂停时刻的剩余轨迹平移/旋转到
  当前实际位姿；回放时间从冻结值续走，不补经过的墙钟时间。重置回合会清除
  接触记忆及上一回合暂停状态。回合时间上限继续按实际仿真时间计。
- 抓取确认、奖励、成功判据、材料/摩擦和加速度上限保持原定义。接触阻挡不写入
  “曾确认抓取后暂停”的历史标志，也不获得抓取成功资格。
- `info` 新增 `replay_contact_blocked`、`replay_gripper_contact_count` 和
  `replay_suspension_reason`，可区分夹爪接触与已确认抓取。

`scenario-v1-89163133198ae4cf` 更新为 `scenario-v1-d1927f8d4dcf06ce`。

## 验证

- 单元检查覆盖单侧手指与夹爪基座、接触顺序、正距离/桌面/其它连杆排除、
  接触抖动、十秒持续阻挡、抓牢转为单侧接触、历史控制版本兼容。
- 在真实 Panda/NERO 模型中，使用合成轨迹库并把线缆端点放到实际单侧手指
  碰撞表面作为初始测试姿态；随后通过普通 `env.step` 积分，保持夹爪打开。
  验证未确认抓取时回放时钟冻结、驱动为零，解除接触后参考在重锚时与实际
  追踪节点位置一致，再按正常步长续走。
- Panda 的该测试姿态保持接触较久；NERO 指面会较快让线缆滑开，因此分别验证
  持续接触与短暂触碰，不把自然脱离误写成持续阻挡。接触与解除测试的姿态设置
  使用直接移动线缆，属于物理接触回归夹具，不是抓取策略评测。
- 无接触对照逐控制步比较 v2/v3 的实际 `qpos`、`qvel` 和回放时钟，要求逐元素
  完全一致。v3 复用连续参考、速度/位置精度、已抓牢暂停与续走、跨 ±π 转动等
  既有积分回归，同时检查重置不会继承接触暂停状态。

结果保存在工作区 `outputs/shape_replay_obstruction_20261013/`，正式回归见
`regression_tests.xml`，共101项测试、18个子检查通过（122.72秒）；场景身份检查
见 `scenario_ids.json`。早期接触回归的
`initial_contact_tests.xml` 保留了 NERO 自然滑开后仍要求持续暂停的测试夹具失败，
正式回归改为与实际接触持续时间对应的检查，没有放宽冻结时钟、重锚或续走断言。

本次处理的是夹爪接触引起的进度积累，不处理其它机械臂连杆或桌面阻挡；也没有
增加释放后速度渐入机制。释放仍会恢复暂停处的参考速度，受原加速度上限约束，
不能据此宣称任意外力扰动后的速度都无尖峰。没有重跑全库或抓取成功率评测。
