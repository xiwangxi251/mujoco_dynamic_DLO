# Shape replay 速度跟踪修正（2026-10-12）

用户要求修正 Shape replay 对轨迹库速度的复现。新版保留物理力驱动、形状保持、
原始材料/摩擦、力加速度上限、公共抓取判据及0.82秒机械臂等待。

## 控制与版本

- 新增 `replay_controller_version`。缺省 `legacy_pd_v1` 保留历史配置的逐帧PD。
  当前七场景族里的 **Shape replay** 显式选择 `continuous_ff_v2`；其它61个
  已注册场景身份保持原样。旧的完整 `ScenarioConfig` / `EnvConfig` 未保存
  此字段时仍按legacy解析；仅按当前注册名称新建配置会选择新版本。
- Shape replay 当前名称仍为 `dev_rigid_replay_shape_nominal_x075_v1`，
  scenario ID 从 `scenario-v1-48ead0f573de9a62` 更新到
  `scenario-v1-89163133198ae4cf`。历史结果不得按名称归入新版。
- 对有效的记录位置和累计yaw使用C2三次插值，在500Hz物理步计算位置及其一、
  二阶导数。有效段末端速度归零，末端之后保持最后位姿。不修改轨迹库、采样时刻
  或回放时间比例。bank本身仍只有50Hz信息，插值不恢复未记录的高频运动。
- 平移和转动均加入参考加速度前馈。由追踪节点反算COM目标时，完整处理
  转动产生的速度、角加速度和向心加速度，时间缩放分别按一阶/二阶缩放。
- v2专用平移增益为800/56，角度增益为160/24；原平移加速度8m/s²、角加速度
  18rad/s²上限保留。没有硬设节点位置或速度，也没有改变线缆/桌面物理参数。
- 确认抓牢时暂停驱动和回放时钟。松开时在**真实暂停时刻**重锚，保持位置连续；
  剩余轨迹按实际yaw与源轨迹暂停yaw之差旋转，不补偿悬挂期间的经过时间。
- `info`及运动配置哈希记录控制版本；v2配置哈希同时包含四个专用增益。

## 有限真实轨迹验证

入口 `tools/evaluation/audit_replay_tracking.py`。NERO、增强6有界DLS、机械臂保持
ready、不运行抓取策略，比较同种子同材料节点（节点20）相对于同一连续参考的
世界XY运动。每回合实测3秒，指标窗口为0.82～3秒；所有对照均未发生机器人接触。
每回合保留完整积分状态、参考与实际采样、配置和哈希。

使用50条评估轨迹库中的六个种子：前三个用于调试，后三个根据旧轨迹诊断中的
较高参考加速度选择，用于检查较急的运动。它们是开发验证，不是50条全库验收，
也不是完整15秒或抓取成功率评测。

## 回归范围与限制

新增测试覆盖连续参考的插值/导数一致性、有效尾段保持、时间缩放、分数时刻
重锚、旧场景身份兼容及控制配置校验；新版复用形状保持、抓取暂停/续走、yaw
跨越±π等既有积分测试，并新增合成解析运动的位置及速度精度断言。

早期合成测试出现的两倍速度来自测试间共享可变配置：时间缩放检查留下了scale=2。
已改为每测试复制配置，未通过放宽速度断言规避问题。

修复测试隔离后，v2完整积分测试类10项及7个子检查通过；最终77项相关单元测试
及解析速度积分检查通过（该次pytest共78项、9个子检查）。原版积分回归在前次
完整运行中已通过；修正后没有改变legacy控制路径。JUnit记录保存在结果目录的
`continuous_tests.xml`与`final_tests.xml`。

以上结果只证明已检查轨迹和测试的改进；限幅、桌面接触和50Hz库精度仍可能造成
跟踪误差。刚体回放仅匹配指定材料节点及整体yaw参考，其余节点刚性共动，不能
同时复现形变场景中所有节点各自的速度。后续正式抓取评测应单独记录新版ID。
