# 简单初态整体运动：五组更改前后配对（2026-10-13）

用户要求判断先前单样本减速是否普遍存在。本次固定五种子，各原版/候选版
各跑2秒，共10个真实物理回合，无夹爪干预。结论：本批 **5/5 均减速**，
运动阶段均速平均相对下降 9.73%，
全部超过原5%速度偏差检查值。不能将这五条短测推广为所有场景或完整15秒结论。

## 原因证据与限制

旧版对所有40个节点施加整体驱动力；候选只对当前有真实桌面接触的节点
施力，实测候选平均接触节点数25.25～28.04/40（时间窗口与表相同）。
所沿用的速度控制是有限比例增益，驱动质量减少后，需要更大的速度误差
才产生抵消阻力的总力。这与本批更慢、平均总前向驱动力仍相近的结果一致。
这是机制和诊断数据支持的主要解释，未做单变量消融来排除构型/转动变化的
贡献，也未自动尝试放大增益或分配补偿。

“无真实接触”包括绳段因几何与约束而略微悬起的情况；本次没有将接触判定
悄悄改成高度阈值，因此留在桌面附近但暂无接触的段也不受候选整体力。

本批证实减速在五个简单运动种子上重复出现；候选机制仍未获用户验收。
本次只在实验工作区保存测试记录（尚未提交），未修改驱动代码或合入dev。
