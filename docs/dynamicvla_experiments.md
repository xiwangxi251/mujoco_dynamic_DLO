# DynamicVLA 实验记录

> 更新日期：2026-08-28

本文记录 DynamicVLA 在四类动态线缆抓取场景中的零样本和 Finetune 实验。当前共评测两组权重：

- `ckt`：零样本权重，没有使用本项目的线缆数据进行微调；
- `cable-four-scenarios-200-latest`：使用本项目采集的 200 条数据进行 Finetune。

项目整体目标与问题见[项目状态](project_status.md)，环境实现见[环境端进度](environment.md)。

## 1. 实验设置

评测使用环境端定义的四个固定场景，具体场景说明见[环境端进度](environment.md)。

```text
instruction = Pick up the blue cable.
protocol    = official_zmq_schema
action      = delta action
control_hz  = 25 Hz
rotation    = quaternion on wire (wxyz)
```

模型通过固定视角相机和腕部相机接收图像，并以闭环方式控制 Panda 完成线缆抓取。

## 2. 零样本实验

`ckt` 是未经本项目线缆数据微调的零样本权重：

```text
/data1/hxai/mujoco/DynamicVLA/ckt
```

目前共完成 40 次零样本评测，没有一次成功：

| 权重 | 训练方式 | 评测次数 | 成功数 | 成功率 |
|---|---|---:|---:|---:|
| `ckt` | 零样本 | 40 | 0 | 0% |

这说明原始 `ckt` 权重在当前动态线缆抓取环境中无法直接完成任务，需要使用任务数据进行适配。

## 3. Finetune 数据

Finetune 使用规则方法采集线缆抓取轨迹。最终训练数据共 200 条，四个场景各 50 条：

| 场景 | 数据量 |
|---|---:|
| Static | 50 |
| Rigid L1 | 50 |
| Shape | 50 |
| Combined L1 | 50 |
| **总计** | **200** |

数据经过成功轨迹筛选后用于 Finetune，对应模型服务标识为
`cable-four-scenarios-200-latest`。

## 4. Finetune 权重评测

Finetune 权重在四个场景中各评测 10 回合，共 40 回合：

| 场景 | 成功数 | 成功率 | Wilson 95% 区间 |
|---|---:|---:|---:|
| Static | 1/10 | 10% | 1.8%–40.4% |
| Rigid L1 | 0/10 | 0% | 0%–27.8% |
| Shape | 1/10 | 10% | 1.8%–40.4% |
| Combined L1 | 0/10 | 0% | 0%–27.8% |
| **总体** | **2/40** | **5%** | **1.4%–16.5%** |

失败模式汇总：

| 失败模式 | 次数 |
|---|---:|
| 从未形成双指候选接触 | 31 |
| 确认抓取后物理滑脱 | 5 |
| 双指候选接触未确认 | 1 |
| 确认抓取后主动张开 | 1 |

40 回合中约 9 回合形成双指候选，8 回合完成抓取确认，最终成功 2 回合。当前首要失败发生在
机械臂接近线缆并形成双指接触之前；Shape 场景还存在确认抓取后的物理滑脱问题。

## 5. 当前问题

模仿学习方法主要直接以图像作为输入，因此依赖大量任务数据。当前数据由规则方法采集，但规则方法
在动态线缆场景中的成功率并不高。为了得到可用于模仿学习的成功示范，需要对采集轨迹进行筛选；
这一过程会优先保留规则方法能够完成的简单样本，并过滤掉大量困难场景或困难状态。即使四个场景的
数据量均为 50 条，也不能保证训练数据覆盖了各场景内部的困难情况。

因此，当前 200 条数据存在明显的数据覆盖问题。后续需要进一步改进数据收集方法，增加困难动态场景
中的有效示范，而不能只依赖现有规则方法成功轨迹的筛选。



数据采集方案调研：
  dynamic vla 数据采集方案
    读取仿真中的物体位置， 物体速度，计算当前速度下 0.23 s 后物体位置，作为抓取位置。将物体速度方向作为夹爪方向。
    随后走一个有限状态机：初始 → 到物体上方 → 下降追物体 → 闭合夹爪 → 抬升 → 移到目标位置
    在  到物体上方、降追物体阶段，目标位置根据当前的 p,v 不断重新计算。到达目标位置后开始闭合夹爪，0.23s后闭合完毕物体正好运动到夹爪内。
    最终DynamicVLA 使用自动数据采集管线获得约20万条仿真轨迹，并在真机上自动采集约2000条数据(平均125条/任务)
  
  puma/ DOMINO数据采集方案
    先在物体静止时，跑一次机器人动作，把静止时物体的位置 作为最终拦截点，根据静态操作算出的机器人所需时间 ，生成一条动态物体轨迹，使物体恰好那个时候到达。
    
    最终 DOMINO自动化仿真数据采集管线并公开了11万余条 expert trajectories（平均 3100 条/任务）。真机遥操采集了  250 条真机示范数据(50 条/任务)

## 6. 当前结论

1. `ckt` 是零样本权重，40 次评测全部失败，当前任务不能依靠零样本直接完成。
2. 使用规则方法采集的 200 条数据进行 Finetune 后，成功率为 2/40（5%），说明微调带来少量成功，
   但整体性能仍然很低。
3. Finetune 的主要瓶颈是接近线缆并形成双指接触；数据筛选造成的困难场景覆盖不足，可能限制了
   模型在动态场景中的表现。
4. 下一步首先需要改进数据收集与数据覆盖，再评估扩大数据量后的 Finetune 效果。
