## 1. 论文 Idea

现有动态操作研究主要关注刚体目标的位置和姿态变化，通常将目标表示为随时间变化的六自由度
状态。然而，扭动的蚯蚓、飘荡的绳子等目标在运动过程中还会持续改变形状，无法用单一目标
位姿描述。

现有非刚体操作方法多从静态状态或已抓持状态开始。少量系统虽能实时识别、跟踪并抓取悬吊
运动布料的角点，但主要依赖预定义目标点和任务特定的高速视觉系统。对于未被抓持、自由运动
且持续发生形变，并且可抓区域也随时间改变的目标，仍缺少明确统一的任务定义和系统研究。

针对这一问题，本项目提出**动态可变形目标操作**任务：机器人需要根据连续观测，对尚未抓持、
自由运动且持续形变的目标完成定位、跟踪和抓取。当前工作首先以动态柔性线缆为代表性对象，
创新点定位在任务提出和系统评测，而不是提出新的控制或学习方法。

暂定题目：**Beyond 6-DoF Motion: Dynamic Manipulation of Continuously Deforming Objects**。

## 2. 代码库最终目标

建立一套可复现、可公平比较、最终能迁移到真机的动态柔性线缆抓取研究平台，研究
Franka Panda 能否根据线缆的整体运动和局部形变，持续完成动态预测、对中、双指夹持、
抬升和稳定保持。

项目不以某一个 PPO checkpoint 或消除所有滑脱为终点。最终应同时交付：

1. 具有可信接触、摩擦、滑脱和动态扰动的 MuJoCo 环境；
2. Scripted、特权 Expert、PPO 和视觉方法使用同一公共成功条件的公平评测；
3. 可复现的场景、seed、模型、完整状态、录像、失败分类和统计产物；
4. 冻结后的 ID/OOD 仿真结果，以及核心条件的真机验证。

## 3. 实验规划

### 3.1 形状变化与整体位置变化

设置四类基础条件，用于区分整体运动和局部形变带来的影响：

1. 线缆静止；
2. 线缆整体平移或旋转，但自身形状基本不变；
3. 线缆持续扭动，发生局部形状变化，但没有显著的整体平移或旋转；
4. 线缆持续改变形状，同时发生整体平移或旋转。

### 3.2 形状变化程度

分别控制下列因素，分析不同动态难度：

- 形状变化幅度；
- 形状变化频率；
- 规律性变化与随机变化。

形状变化幅度和频率应作为独立因素控制，避免把“变化更大”和“变化更快”混为同一种难度。

### 3.3 OOD 泛化测试

- 训练阶段未出现的运动规律；
- 不同线缆长度；
- 不同线缆材质，包括质量、柔软程度、阻尼和摩擦特性的变化。

### 3.4 对比方法

- 追踪线缆单个目标点的控制算法；
- 强化学习方法；
- π0.5（计划接入）；
- Diffusion Policy（计划接入）；
- DynamicVLA；
- 特权 Expert，作为诊断性性能上界。

所有方法使用相同的场景、随机种子、机器人约束和任务成功判定进行比较。详细场景参数、样本量、
ID/OOD 划分和统计方式由[实验协议](reference/experiment_protocol.md)维护。

### 4.4 目前的问题

1. 现有 DLO 操作研究中的 RL 方法，大多将 DLO 状态（例如线缆上若干节点的位置）作为输入。
   仿真中通常可以直接获取环境给出的 DLO 状态，真机中则需要通过视觉方法估计。然而，实时识别
   运动中 DLO 的完整状态比较困难。后续需要研究适用于动态 DLO 的感知算法，或者考虑将图像特征
   直接输入 RL。后者会面临更大的 sim-to-real 差异，而且 RL 方法难以直接在真机上进行大规模训练。
2. 模仿学习方法通常直接以图像作为输入，因此需要采集训练数据。目前规则方法在动态线缆场景中的
   成功率不高；如果只筛选成功轨迹，困难场景的数据会被大量过滤，导致数据分布偏向简单场景。
   后续需要进一步改进数据收集方法。

#### 真机实验的形式问题

仿真环境可以较精确地控制线缆的运动形式和任务难度，但真机实验中如何可控、可重复地产生线缆运动，
目前还没有确定方案：

1. **水中漂浮振荡或风力吹动线缆**：运动不易控制，任务难度难以量化，同一场景也难以准确复现。
2. **使用电机驱动的机器蛇**：可以持续产生形状变化，但其本体由主动刚性关节组成；常见产品的
   自由度、长度和弯曲幅度有限，与柔性线缆仍有差异。
3. **使用电机驱动柔性线缆**：需要自行设计驱动装置，而且驱动点会对线缆形态引入额外的边界约束。

## 5. 参考文献与相关工作

### 5.1 动态操作

#### [DynamicVLA: A Vision-Language-Action Model for Dynamic Object Manipulation](https://arxiv.org/abs/2601.22153)（2026）

- **任务：** 面向持续运动目标的通用动态操作，涵盖动态交互、时空感知和未见运动模式泛化。
- **方法：** 使用 0.4B 参数的轻量 VLA，并提出 Continuous Inference，使推理与动作执行重叠；
  Latent-aware Action Streaming 根据最新预测丢弃过时动作，减小推理延迟导致的感知—执行错位。
- **数据与评测：** 提出 Dynamic Object Manipulation（DOM）benchmark，包含大规模仿真数据和真机数据，
  并在 Franka 与 PiPER 上进行动态操作评测。
- **与本项目的关系：** 解决运动目标下的实时感知、预测和连续控制问题，但研究对象主要仍以运动中的
  刚体目标为主，没有把持续形变本身作为任务变量。

#### [Towards Generalizable Robotic Manipulation in Dynamic Environments](https://arxiv.org/abs/2603.15620)（PUMA / DOMINO，2026）

- **任务：** 研究动态环境中的通用机器人操作，以及策略对不同任务复杂度和运动模式的泛化能力。
- **DOMINO：** 包含 35 个动态操作任务、超过 11 万条专家轨迹，并从多个维度评估动态操作能力。
- **PUMA：** 使用场景中心的历史光流建模运动历史，并通过专门的 world queries 隐式预测目标未来状态，
  将历史感知与短时预测结合起来生成动作。
- **与本项目的关系：** 强调动态数据、历史视觉信息和未来状态预测，但没有专门研究线缆等目标在运动
  过程中持续改变形状的问题。

### 5.2 DLO 操作方法调研

#### [Hierarchical DLO Routing with Reinforcement Learning and In-Context Vision-language Models](https://arxiv.org/abs/2510.19268)（ICRA 2026）

- **任务：** 柔性线缆的长时程多卡扣布线。机器人根据语言指令，按照指定顺序将线缆依次穿过多个
  不同位置和方向的 clip。
- **方法：** 使用分层操作框架。高层 VLM 根据场景图像、任务指令和执行历史，选择下一目标及
  `Insert`、`Pull`、`Flatten` 等技能；低层针对困难的插入过程使用 SAC，根据低维几何状态预测
  抓取位置和插入轨迹参数，拉线和展平采用预定义运动基元。失败检测和 `Flatten` 提供恢复能力。
- **RL 输入：** DLO 离散粒子位置 `p1:n` 和当前 clip 位姿。
- **RL 输出：** 7 维 Insert 参数，包括 1 维 DLO 抓取点索引，以及两个 waypoint；每个 waypoint
  包含二维位置和 1 维夹爪旋转角。
- **Sim-to-real：** SAC 在仿真中训练，并随机化 DLO 位姿和 clip 条件；真机通过 RGB 分割恢复与
  仿真一致的 DLO 几何状态，策略直接部署，不进行真机微调。

#### [DexDLO: Learning Goal-Conditioned Dexterous Policy for Dynamic Manipulation of Deformable Linear Objects](https://arxiv.org/abs/2312.15204)（ICRA 2024）

- **任务：** 使用灵巧手完成抓取滑动中的线缆、拉线、端点位置控制和弯曲等动态 DLO 操作，并统一
  表述为“控制线缆指定关键点到达目标位置”的 goal-conditioned manipulation 问题。
- **方法：** 使用 PPO，以灵巧手状态、DLO 离散关键点、目标位置及相对几何关系作为低维输入，
  直接输出 Shadow Hand 的关节控制。通过连续 4 帧状态堆叠表示线缆动态，并使用
  pose-regularized reward，使目标点接近目标的同时保持线缆位于手指可控区域。
- **RL 输入：** 灵巧手关节位置和速度、25 个 DLO 关键点的三维位置、指尖和手掌位置、目标位置，
  以及 DLO 与手掌、指尖之间的相对距离和向量；实际输入为连续 4 帧堆叠。
- **RL 输出：** 20 维 Shadow Hand 关节目标角度。
- **Sim-to-real：** 没有真机实验。

#### [Robotic Assembly of Deformable Linear Objects via Curriculum Reinforcement Learning](https://doi.org/10.1109/LRA.2025.3553676)（IEEE RA-L 2025）

- **任务：** 机器人使用通用两指夹爪夹持连接器后方的柔性线缆，并在不同弯曲程度下完成 Type-C
  插头插入；主要困难是线缆弯曲引起的连接器位姿变化和接触卡阻。
- **方法：** 使用 RLPD，结合在线交互数据和少量遥操作示范。自适应课程根据成功率逐渐增加初始
  线缆弯曲程度；视觉状态分类器和弯曲角度构成两阶段奖励，引导机器人先找到并部分插入插座，再
  利用接触逐渐拉直线缆并完成插入。
- **RL 输入：** 双视角 RGB 图像、末端位移、三维力和连接器弯曲角；两路 64×64 RGB 图像由
  ResNet-10 编码。
- **RL 输出：** 3 维笛卡尔位移。
- **Sim-to-real：** 直接在真机上训练 RL。

#### [Self-Curriculum Model-based Reinforcement Learning for Shape Control of Deformable Linear Objects](https://arxiv.org/abs/2602.21816)（IROS 2026）

- **任务：** 双臂分别抓住 DLO 两端，将线缆从任意初始形状控制到指定目标形状，重点处理初始形状
  与目标形状差异很大、甚至曲率相反的情况。
- **方法：** 采用两阶段控制。大形变阶段使用基于 MBPO 和 SAC 的模型强化学习，通过 Bi-LSTM
  ensemble 学习 DLO 动力学并生成虚拟交互；Self-Curriculum 自动选择当前中等难度且形状多样的
  目标。接近目标后切换到 Jacobian-based visual servoing，完成小形变高精度调整。
- **RL 输入：** 当前 DLO 关键点位置、两个机械臂的末端位姿和目标 DLO 关键点位置。
- **RL 输出：** 机械臂末端动作位姿增量。
- **Sim-to-real：** 仿真和真机使用固定数量的 DLO 关键点作为一致的状态表示；RL 负责大形变粗
  控制，接近目标后由真机在线 Jacobian visual servo 精调，RL 策略 zero-shot 迁移。

#### [Multi-Stage Cable Routing through Hierarchical Imitation Learning](https://arxiv.org/abs/2307.08927)（IEEE T-RO 2024）

- **任务：** 机器人将柔性线缆依次穿过多个 clip，重点解决单次穿线失败在长时程任务中不断累积，
  以及固定技能序列无法可靠恢复的问题。
- **方法：** 使用分层模仿学习。低层只对最困难的 `Route` 技能进行视觉模仿学习，并结合
  `Pickup`、`Perturb Cable`、`Go Next` 等规则运动基元；示范中包含失败恢复轨迹。高层根据多视角
  视觉、机器人状态和最近技能历史，学习选择下一 primitive，并在失败后重试、整理线缆或重新抓取。
- **IL 输入：** 双视角 wrist RGB 图像和 1 维 TCP 高度。
- **IL 输出：** 4 维机械臂末端位姿增量。
- **Sim-to-real：** 主要通过真机示范训练视觉策略，不以仿真到真机迁移为主要设置。

#### [DLO-Lab: Benchmarking Deformable Linear Object Manipulations with Differentiable Physics](https://arxiv.org/abs/2606.04206)（ICML 2026）

- **问题：** DLO 操作缺少统一、高保真的仿真环境和标准化评测任务。
- **方法：** 提出基于 Genesis 和可微分物理的 DLO 仿真与 benchmark。使用 Discrete Elastic Rod
  描述拉伸、弯曲、扭转、塑性形变及复杂接触，并支持物理过程的梯度反传；平台支持 PPO、SAC、
  SHAC、SAPO 和直接梯度轨迹优化等方法，包含绕线、穿环、解结和形状控制等 10 类任务。针对
  长时程任务，还使用 VLM 选择抓取点和进行任务分解。
- **RL 输入：** 完整 DLO 状态和机器人状态，包括所有 DLO 顶点的位置与速度、机械臂末端位姿和
  关节位置。
- **RL 输出：** 每个控制点或夹爪的 6 维末端动作。
- **Sim-to-real：** 先用仿真拟合真实线缆物理参数；训练时构造带高斯深度噪声的点云模拟真机感知，
  真机使用相同形式的点云输入，PPO 直接 zero-shot 部署。

#### [SILO: Simulation-in-the-Loop Sim-to-Real Transfer for Multi-Stage Cable Routing](https://arxiv.org/abs/2607.04616)（2026）

- **问题：** 多阶段线缆布线中的 RL 策略难以从仿真直接迁移到真机。
- **方法：** 先在 GPU 并行仿真中用 PPO 学习局部穿 clip 策略；真机部署时，以双目视觉恢复局部
  线缆状态。策略动作不直接发送到真机，而是先在与真机同步的仿真机器人中执行一步，再让真机
  跟踪仿真产生的下一步关节目标，以减小低层控制器和动力学响应差异。
- **RL 输入：** 夹爪后方最近 4 个线缆点的三维位置、TCP 末端位姿和机器人关节角。
- **RL 输出：** 7 维关节位置增量。
- **Sim-to-real：** 真机通过视觉估计线缆状态；simulation-in-the-loop 在执行阶段保留仿真控制器，
  由真机跟踪仿真产生的关节目标。

#### [Learning Dynamic Rope Manipulation Using Task-Level Iterative Learning Control](https://arxiv.org/abs/2602.21302)（RSS 2026）

- **问题：** 高速动态绳索操作中，人类示范轨迹难以直接迁移到机器人，而绳索惯性、柔性和自碰撞
  又难以精确建模。论文以动态甩绳打结为主要任务。
- **方法：** 提出 Task-Level Iterative Learning Control。先由单次人类示范产生初始机器人轨迹，
  再在真机上反复执行，根据绳索实际运动与目标状态的误差修正下一次完整动作轨迹。优化目标集中于
  决定成败的 critical point，例如绳索首次自碰撞时的位置和速度，而不是逐点复现完整人类轨迹。
- **输入与输出：** 输入是关键时刻观测到的绳索任务空间误差；输出是对下一次整条机器人命令轨迹
  的更新。
- **Sim-to-real：** 不采用常规的大规模仿真训练再迁移；使用简化绳索模型提供更新方向，并通过少量
  真机迭代直接适应不同绳索动力学。
