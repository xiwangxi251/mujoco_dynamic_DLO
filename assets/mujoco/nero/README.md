# AgileX NERO MuJoCo assets

The XML model and mesh files in this directory are copied from the AgileX
robotics simulation repository:

<https://github.com/agilexrobotics/agx_arm_sim/tree/master/mujoco/agilex_arm/agilex_nero>

The upstream repository identifies its project license as MIT. These files
are kept under `assets/mujoco/nero/` so the NERO simulation does not depend on
an external checkout at runtime.
